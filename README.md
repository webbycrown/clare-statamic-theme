# Clare Statamic Theme

Fashion catalog starter kit from the Clare eCommerce HTML theme.

Catalog and content pages only. There is no checkout, cart, or payment.

## Pages
- Home V1 / V2 / V3
- Shop grid, list, right sidebar, three column
- Categories and product detail (3 layouts)
- Blog grid, classic, and detail layouts
- About, contact, FAQ, privacy, terms
- Login, register, account profile

Product inquiry and contact forms replace purchase.
