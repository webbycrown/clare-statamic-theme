# Third-party libraries

Clare ships the following third-party front-end libraries. All are loaded from local copies bundled in `public/assets`.

| Library | Version | Licence | Purpose |
|---|---|---|---|
| [jQuery](https://jquery.com) | 3.x | MIT | DOM utilities, AJAX forms |
| [Swiper](https://swiperjs.com) | 9.x | MIT | Hero sliders, product carousels |
| [Magnific Popup](https://dimsemenov.com/plugins/magnific-popup/) | 1.x | MIT | Image lightboxes, video popups |
| [Isotope](https://isotope.metafizzy.co) | 3.x | GPL-3 / Commercial | Product grid filtering |
| [imagesLoaded](https://imagesloaded.desandro.com) | 5.x | MIT | Image-load detection (Isotope) |
| [Font Awesome](https://fontawesome.com) | 6.x Free | Font Awesome Free Licence | Brand + UI icons |
| [Themify Icons](https://themify.me/themify-icons) | 1.x | MIT | Additional UI icons |
| [Bootstrap](https://getbootstrap.com) | 5.x | MIT | Grid, utilities |
| [Montserrat](https://fonts.google.com/specimen/Montserrat) | — | OFL-1.1 | Body typeface (Google Fonts) |

> Isotope is free for open-source projects and requires a commercial licence for closed-source use. See [isotope.metafizzy.co/#license](https://isotope.metafizzy.co/#license).
